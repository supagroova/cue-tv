# Device Proof

Use docs/agent-harness/templates/device-proof.md and the current plan gate. Verify actual model/OS/build and fixture permission; pin the tested dependency/toolchain configuration. Pair/install only within the session's authorized scope. A disposable experiment answers a named decision; mark it experimental and do not silently promote it to production.

Prove peer transfer independently from web seeds/debrid/HTTP media; isolate HTTP(S) tracker, UDP and DHT cases. Record verified downloaded bytes at first frame and seek to uncached data. Include cancelled blocked reads, repeated source switches, cache limits and foreground exit. Repeat independence with Mac disconnected and Pi off.

For performance compare like builds, profiles, cache state and swarm conditions; count errors, alternate comparisons, report median/range and sample count, identify limiter and include user-visible end-to-end time. A noisy or incomplete run is inconclusive. Never generalize a prototype's UDP failure to all tvOS implementations.

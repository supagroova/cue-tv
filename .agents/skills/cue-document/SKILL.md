# Document

Identify reader and purpose: tutorial, procedure, reference, rationale or experiment. Keep operational docs about current behavior, while dated plans/research/evidence retain their historical context. Link one source of truth rather than duplicate policy. Commands need a working directory, prerequisites, expected output and honest limits.

Run make check for harness links/skills and the relevant documented command when safe. Review semantic accuracy separately. Update docs/agent-harness/HANDOFF.md with current task, content/branch identity, exact checks, next action and unresolved hardware/setup. Keep raw transcripts, account configuration, credentials and viewing data out. Report measured results with conditions and counts; no unsupported claims that a hook, CI or physical test ran.

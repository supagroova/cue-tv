# Investigate

Read the current implementation and tests, then plan/research and relevant history when Git is available. Trace UI action → service/Core → session → engine/bytes → player → saved state. Distinguish observed code, upstream claim, experiment and inference. Missing history in a snapshot is a gap, not proof that a decision never existed.

For rationale, seek a concrete code anchor and the relevant decision. Use only connected sources needed for this request, not every Livestorm integration. Give alternatives and uncertainty where records cannot settle intent. For resume, use current handoff and task evidence; do not search unrelated chats or provider transcript stores. For read-only questions, return findings without edits or shipping.
